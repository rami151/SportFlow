
# SportFlow

## SOA Mini-Project 2026

SportFlow is a sports competition management
platform based on a microservices architecture.

## Technologies

- Java 17
- Spring Boot 3
- Spring Cloud Gateway
- Spring Security and JWT
- REST
- SOAP
- gRPC
- RabbitMQ
- PostgreSQL
- Docker

## Team

- Dhia: Gateway, Security, REST and SOAP
- Rami: Competition, gRPC and RabbitMQ

## Architecture

The platform is divided into independent
microservices communicating through REST,
SOAP, gRPC and RabbitMQ.
